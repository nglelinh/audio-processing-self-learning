An intrusive metric scores an enhanced waveform against a clean reference of the same utterance. Scale-invariant signal-to-distortion ratio (SI-SDR), introduced by Le Roux, Wisdom, Erdogan, and Hershey in “SDR – Half-baked or Well Done?” (ICASSP 2019), is the number most speech-enhancement labs print first. It answers a narrow question: after the best global gain is removed, how much of the estimate is still not the reference? It does not answer whether the result sounds metallic, whether consonants survived, or whether a meeting client can run the model on time. This lesson builds the formula, a NumPy lab with printed floats, and the alignment failures that make the number lie.

## What you should be able to do

You should be able to compute SI-SDR from the projection formula, explain why a pure gain leaves the score perfect, and explain why a one-sample delay can collapse it. You should report SI-SDR only on pairs you have aligned, and you should refuse to treat a high score as permission to skip a listening check.

## Intrusive setup

Keep three signals distinct. The clean reference is $$s$$. The microphone mixture is $$x = s + n$$, useful for input SNR and for ΔSI-SDR, but it is not the reference. The enhancer output is $$\hat{s}$$. SI-SDR compares $$s$$ and $$\hat{s}$$ at the same sample rate, the same length, and the same time origin. If the enhancer is DeepFilterNet-style, algorithmic latency from the STFT hop and any look-ahead must be removed before the inner product. A positive delay of even one hop dumps reference energy into the residual and the score falls off a cliff.

## From SDR to SI-SDR

Classical SDR treats every gain error as distortion:

$$
\mathrm{SDR} = 10 \log_{10} \frac{\| s \|^2}{\| \hat{s} - s \|^2}
$$

If $$\hat{s} = 2s$$, the residual is as large as the reference and SDR is 0 dB, even though a listener hears the same waveform louder. Scale-invariant SDR first projects the estimate onto the reference, which is the optimal scalar gain in the least-squares sense:

$$
s_{\mathrm{target}} = \frac{\langle \hat{s}, s \rangle}{\| s \|^2}\, s
$$

$$
e_{\mathrm{noise}} = \hat{s} - s_{\mathrm{target}}
$$

$$
\mathrm{SI\text{-}SDR} = 10 \log_{10} \frac{\| s_{\mathrm{target}} \|^2}{\| e_{\mathrm{noise}} \|^2}
$$

The target is the part of $$\hat{s}$$ that is a scaled copy of $$s$$. Everything orthogonal to $$s$$ is distortion. A pure gain makes $$e_{\mathrm{noise}} = 0$$ and the ratio goes to $$+\infty$$. Some library ports of Le Roux et al. also subtract the mean of each vector before the projection. This lesson’s lab does **not** remove the mean, so your printout must match the floats below. If a helper function zero-means, it will not print 13.80 on this pair.

## A numeric pair you can recompute

Take $$s = [1, 0, -1, 0.5]$$ and $$\hat{s} = [0.8, 0.1, -0.7, 0.6]$$. The projection coefficient is $$\langle \hat{s}, s \rangle / \|s\|^2$$. The residual is small but not zero, and SI-SDR prints **13.80 dB**. Shift the estimate by one sample, $$\hat{s}_{\mathrm{delay}} = [0, 0.8, 0.1, -0.7]$$, and the same function prints **−10.67 dB**. Nothing about the spectrum changed in a deep way; the time origin did. That is why every batch script in this course aligns before it averages.

When a mixture $$x$$ is available, also report improvement:

$$
\Delta\mathrm{SI\text{-}SDR} = \mathrm{SI\text{-}SDR}(\hat{s}, s) - \mathrm{SI\text{-}SDR}(x, s)
$$

A model that scores 12 dB on an already-clean file can have a negative delta. Input SNR of the mixture is a different quantity: it compares $$s$$ to $$n$$, not $$\hat{s}$$ to $$s$$.

## Alignment checklist

Prefer generating the reference at the model rate (48 kHz in the DeepFilterNet papers) and document any resample. Trim both sides to the same length and write down which tail you cut. Compensate a known hop delay, or estimate it once on a calibration clip and freeze that shift. Compare mono to mono. Global gain is free under SI-SDR. A compressor that pumps inside the utterance is not, and neither is residual echo the reference never contained.

## Why a high score can still sound metallic

SI-SDR is an energy ratio after one scalar. It does not care whether the residual sits in a consonant or in a musical tone between harmonics. Over-suppression can delete noise and fricatives together and still look fine on a loud vowel. A reverberant estimate against a dry reference is punished even when dereverberation was never the product goal. Clipping, a stereo mixup, or a later switch to mean removal all move the number without a matching change in `setSuppressionLevel`. The figure is the rule: SI-SDR is one column. DNSMOS (08-02) and a listening note (08-03) are the others. RTF is a separate gate. Pin a DNS Challenge year from [microsoft/DNS-Challenge](https://github.com/microsoft/DNS-Challenge) when you copy a public protocol.

PESQ and STOI show up in DNS reports and in the DeepFilterNet papers. Both still need a time-aligned reference. Neither replaces a human check when the voice sounds underwater.

## Mini-lab

Hard-code the two vectors. Do not download a dataset. Run this file as `python3 si_sdr_lab.py`.

```python
import numpy as np

def si_sdr(reference, estimate):
    reference = np.asarray(reference, dtype=float)
    estimate = np.asarray(estimate, dtype=float)
    target = (np.dot(estimate, reference) / np.dot(reference, reference)) * reference
    noise = estimate - target
    return 10 * np.log10(np.dot(target, target) / np.dot(noise, noise))

s = np.array([1.0, 0.0, -1.0, 0.5])
s_hat = np.array([0.8, 0.1, -0.7, 0.6])
s_hat_delayed = np.array([0.0, 0.8, 0.1, -0.7])
print(f"{si_sdr(s, s_hat):.2f}")
print(f"{si_sdr(s, s_hat_delayed):.2f}")
```

Expected output:

```text
13.80
-10.67
```

Failure modes you should hit on purpose once:

- Drop the delay line and you will think every model scores about 14 dB. The second print is the alignment alarm.
- Pass vectors of different lengths and NumPy raises on the dot product. Trim explicitly.
- Feed $$x$$ instead of $$s$$ as the reference and the function still returns a float. The float is not SI-SDR of the enhancement.
- Set `estimate = 2 * reference`. The noise energy is zero and `log10` warns or returns `inf`. That is a perfect scale match, not a bug in the formula. Do not add an epsilon and then claim 80 dB.
- Import a library SI-SDR that subtracts the mean. It will not print 13.80. Either match this projection or label the variant.

### Answer hints

1. $$\langle \hat{s}, s \rangle = 0.8\cdot 1 + 0 + (-0.7)\cdot(-1) + 0.6\cdot 0.5 = 1.8$$, $$\|s\|^2 = 1 + 0 + 1 + 0.25 = 2.25$$, so the scale is $$1.8/2.25 = 0.8$$. Finish the norms in NumPy if the arithmetic gets messy; the print is 13.80.
2. A larger shift usually lowers the score further on this short vowel-like vector, because less of the estimate lands on $$s$$. Report the float you compute; do not copy −10.67.
3. Delta is output SI-SDR minus input SI-SDR. The input term uses $$x$$, not $$\hat{s}$$.
4. Publish SI-SDR only for synthetic pairs with a stored clean file and a documented shift. Real calls get `n/a`. Metallic timbre is residual structure SI-SDR does not classify.
5. Same rate (48 kHz), same length, delay at least on the order of the hop (10 ms is 480 samples) plus any look-ahead the paper states, mono only.
